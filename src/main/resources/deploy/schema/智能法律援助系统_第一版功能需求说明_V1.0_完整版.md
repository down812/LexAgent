# 基于多 Agent 协作与 RAG 的智能法律援助系统

# 第一版功能需求说明（V1.0）

## 1. 版本目标

### 1.1 版本定位

本版本目标是完成智能法律援助系统的核心闭环，验证 Multi-Agent 与 RAG
技术在法律知识科普场景中的可行性。

核心流程：

    用户登录
     ↓
    法律智能问诊
     ↓
    Case Analysis Agent
     ↓
    Legal Search Agent
     ↓
    RAG 法律知识库
     ↓
    Legal Analysis Agent
     ↓
    Reviewer Agent
     ↓
    法律依据展示
     ↓
    风险提示

------------------------------------------------------------------------

# 2. 第一版系统范围

第一版聚焦核心链路，不实现复杂业务扩展。

包含：

-   用户登录
-   法律智能问答
-   案件事实分析 Agent
-   法律检索 Agent
-   RAG 法律知识库
-   法律分析 Agent
-   法律核验 Agent
-   法律依据展示
-   风险提示
-   SSE 流式输出

暂不包含：

-   案件长期管理
-   证据文件 OCR
-   自动生成法律文书
-   在线律师服务
-   用户社区
-   复杂后台管理

------------------------------------------------------------------------

# 4. 法律智能问诊

## 4.1 功能描述

用户使用自然语言描述法律问题。

示例：

> 公司工作两年后突然辞退，没有支付补偿，我应该怎么办？

系统不会直接生成答案，而进入多 Agent 协作流程。

------------------------------------------------------------------------

# 5. Case Analysis Agent

## 5.1 功能目标

将用户自然语言描述转换为结构化案件信息。

输入：

    用户法律问题

输出：

``` json
{
 "domain":"劳动法",
 "caseType":"劳动合同解除",
 "facts":[
   "工作两年",
   "公司主动辞退",
   "未支付补偿"
 ],
 "disputePoints":[
   "解除是否合法",
   "是否需要赔偿"
 ],
 "missingInformation":[
   "解除理由",
   "工资情况"
 ]
}
```

## 5.2 功能要求

-   识别法律领域
-   提取案件事实
-   判断争议焦点
-   识别缺失信息
-   必要时向用户发起追问

------------------------------------------------------------------------

# 6. Legal Search Agent

## 6.1 功能目标

根据案件分析结果检索相关法律法规。

流程：

    案件信息
     ↓
    生成查询条件
     ↓
    向量检索
     ↓
    Elasticsearch
     ↓
    返回相关法律条文

输出：

-   法律名称
-   条款编号
-   条款内容
-   法律领域
-   生效状态

------------------------------------------------------------------------

# 8. Legal Analysis Agent

## 8.1 功能目标

结合：

    案件事实
    +
    法律依据
    +
    检索结果

生成法律分析。

输出：

-   涉及法律问题
-   法律依据
-   案件分析
-   处理建议

------------------------------------------------------------------------

## 8.2 约束要求

必须：

-   基于知识库内容
-   不编造法律条款
-   对不确定信息进行说明

------------------------------------------------------------------------

# 9. Reviewer Agent

## 9.1 功能目标

对法律分析结果进行可信度审核。

审核内容：

## 法律依据检查

确认：

-   法律是否真实存在
-   条款是否有效

## 条款匹配检查

判断：

-   条款是否支持当前结论

## 事实一致性检查

避免：

-   编造用户未提供的信息

## 风险表达检查

避免：

错误表达：

    你一定胜诉
    公司一定违法
    一定获得赔偿

优化为：

    根据目前信息，可能涉及……
    具体结果需要结合完整事实判断。

------------------------------------------------------------------------

# 10. 最终法律回答

输出结构：

    【初步判断】

    ……

    【法律依据】

    法律名称
    条款编号
    法律内容

    【结合你的情况】

    ……

    【处理建议】

    ……

    【风险提示】

    以上内容用于法律知识科普，
    不能替代专业法律意见。

------------------------------------------------------------------------

# 11. SSE 流式输出

系统支持实时展示处理过程。

事件：

    agent_start
    agent_result
    citation
    content
    done

示例：

    案件分析完成

    法律法规检索完成

    法律分析完成

    法律依据核验完成

    正在生成回答……
