### 核心算法
#### 1. 向量召回（复用阶段一 VectorStore）
- `VectorStore.similaritySearch()` + similarityThreshold=0.05（召回期放低阈值）
- 召回数 = topK × 4（给 rerank 更多候选）

#### 2. 关键词召回（ES match query）
- 注入 `ElasticsearchClient`（elasticsearch-java 8.15.5，Spring Boot 自动配置）
- `match` query 搜 text 字段，可选 `term` filter 按 datasetId 过滤
- 返回 BM25 分数

#### 3. RRF 融合（Reciprocal Rank Fusion）
- 公式：score = Σ 1/(k + rank_i)，k=60（标准常数）
- 按 law_name + article_no + content前缀 去重合并两路结果
- 命中类型标记：VECTOR（仅向量）/KEYWORD（仅关键词）/HYBRID（两路命中）

#### 4. Reranker 多特征加权（法律场景核心创新）
综合分 = baseScore + featureBonus
- baseScore = vectorScore×0.4 + rrfScore×2.0
- 特征1：条款号精确匹配 ×3.0（用户提到"第四十条"，候选含"第四十条"）—— 法律检索核心特征
- 特征2：法律名匹配 ×1.5
- 特征3：关键词覆盖率 ×2.0（query 实词在 content 命中比例）
- 特征4：内容长度归一化（过短惩罚 -0.3）

设计考量：不依赖外部 LLM，纯算法稳定可复现，论文好讲"面向法律场景的多特征加权重排"

#### 5. 条款校验（防幻觉）
- 检索结果提取 law_name + article_no
- 查 MySQL legal_laws → legal_articles 验证存在性
- 精确匹配 article_no → 模糊 like → 反向 like
- 内容相似度校验（Hutool TextSimilarity.similar），防向量漂移
- 结果分级：verified=true（高可信）/ verified=false（疑似幻觉）
